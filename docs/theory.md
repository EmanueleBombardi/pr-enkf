# PR-EnKF: theory and implementation

This document describes the Parameter-Regularised Ensemble Kalman Filter (PR-EnKF) as implemented in this repository, and maps each step of the Python code ([`pr_enkf/filter.py`](../pr_enkf/filter.py)) to the OpenFOAM implementation ([`openfoam/`](../openfoam)). The method is introduced in Bombardi et al. (2026), [arXiv:2607.03571](https://arxiv.org/abs/2607.03571).

## 1. Notation

| Symbol | Meaning | Python | Shape |
|---|---|---|---|
| $`\boldsymbol{\psi}`$ | augmented state (parameters and predicted observables) | | |
| $`\boldsymbol{\alpha} = \mathbf{M}_\alpha\boldsymbol{\psi}`$ | model parameters | `alpha` | $`(n_\alpha, N)`$ |
| $`\mathbf{q} = \mathbf{M}_q\boldsymbol{\psi}`$ | predicted observables | `q` | $`(n_q, N)`$ |
| $`\mathbf{d}`$ | measurements | `d` | $`(n_q,)`$ |
| $`\mathbf{C}_{dd} = \sigma_d^2\mathbf{I}`$ | measurement error covariance | `sigma_d` | scalar |
| $`\mathbf{p}`$ | literature-consistent parameter values | `p` | $`(n_\alpha,)`$ |
| $`\boldsymbol{\gamma}`$ | relative uncertainty of $`\mathbf{p}`$ | `gamma` | $`(n_\alpha,)`$ |
| $`\mathbf{C}_{pp}`$ | uncertainty of $`\mathbf{p}`$ (diagonal) | | |
| $`N`$ | ensemble size | `n_ens` | |
| $`\rho`$ | multiplicative inflation factor | `inflation` | |

Ensemble arrays store one member per column. An overbar denotes the ensemble mean.

## 2. Cost function

Each ensemble member is updated to the minimum of

```math
\mathcal{J}(\boldsymbol{\psi}) =
\left\|\boldsymbol{\psi}^{f} - \boldsymbol{\psi}\right\|^{2}_{(\mathbf{C}^{f}_{\psi\psi})^{-1}}
+ \left\|\mathbf{d} - \mathbf{M}_q\boldsymbol{\psi}\right\|^{2}_{\mathbf{C}_{dd}^{-1}}
+ \left\|\mathbf{p} - \mathbf{M}_\alpha\boldsymbol{\psi}\right\|^{2}_{\mathbf{C}_{pp}^{-1}},
```

which penalises, respectively, departures from the forecast $`f`$ (the current model prediction), the misfit to the measurements, and departures of the parameters from their literature-consistent values. The standard EnKF is recovered as $`\mathbf{C}_{pp}\to\infty`$.

The second and third terms have the same structure: both compare a linear extraction of $`\boldsymbol{\psi}`$ with given values. Minimising $`\mathcal{J}`$ is therefore equivalent to a standard EnKF update in which $`\mathbf{p}`$ is treated as an additional set of observations, the **pseudo-observations** of the parameters. For each member $`j`$, the predicted and observed vectors become

```math
\mathbf{y}_j = \begin{bmatrix} \mathbf{q}_j \\ \boldsymbol{\alpha}_j \end{bmatrix},
\qquad
\tilde{\mathbf{d}}_j = \begin{bmatrix} \mathbf{d}_j \\ \mathbf{p}_j \end{bmatrix},
\qquad
\mathbf{C} = \begin{bmatrix} \mathbf{C}_{dd} & \\ & \mathbf{C}_{pp} \end{bmatrix},
```

where $`\mathbf{d}_j`$ and $`\mathbf{p}_j`$ are the perturbed measurements and pseudo-observations defined in Section 3.

The regularisation is adaptive: its strength depends on the relative uncertainty of the literature-consistent values and on the ensemble-estimated parameter covariance. Parameters well constrained by the measurements can depart from $`\mathbf{p}`$, whereas parameters for which the data provide limited information remain close to their literature-consistent values.

Only the parameters are updated. The model state (e.g. the flow field) is regenerated by the model from the updated parameters at the next iteration, so the procedure is iterative: run the model for every member, update the parameters, repeat.

## 3. Initialisation and perturbations

The initial ensemble is drawn around the literature-consistent values with their relative uncertainty:

```math
\boldsymbol{\alpha}_j^{(0)} = \mathbf{p} \circ \left(\mathbf{1} + \boldsymbol{\gamma} \circ \boldsymbol{\xi}_j\right),
\qquad \boldsymbol{\xi}_j \sim \mathcal{N}(\mathbf{0}, \mathbf{I}).
```

The perturbed measurements and pseudo-observations are

```math
\mathbf{d}_j = \mathbf{d} + \boldsymbol{\varepsilon}_j,\quad \boldsymbol{\varepsilon}_j \sim \mathcal{N}(\mathbf{0}, \mathbf{C}_{dd}),
\qquad
\mathbf{p}_j = \mathbf{p} \circ \left(\mathbf{1} + \boldsymbol{\gamma} \circ \boldsymbol{\eta}_j\right),\quad \boldsymbol{\eta}_j \sim \mathcal{N}(\mathbf{0}, \mathbf{I}).
```

They are drawn **once** and reused at every iteration, so that each member converges towards a fixed target instead of following a new noise realisation at every step.

## 4. The analysis step

The steps below correspond to the numbered comments in `analysis()`.

**1. Augmented vectors.** Build $`\mathbf{y}_j`$ and $`\tilde{\mathbf{d}}_j`$ as in Section 2. For the standard EnKF, $`\mathbf{y}_j = \mathbf{q}_j`$ and $`\tilde{\mathbf{d}}_j = \mathbf{d}_j`$.

**2. Normalisation.** Parameters are scaled by the absolute value of the current ensemble mean, observables by the measurement uncertainty:

```math
\mathbf{T} = \mathrm{diag}\!\left(|\bar{\boldsymbol{\alpha}}|\right),
\qquad
\boldsymbol{\Lambda} = \mathrm{diag}\!\left(\sigma_d\mathbf{1}_{n_q},\; |\bar{\boldsymbol{\alpha}}|\right),
```

with $`|\bar\alpha_i|`$ floored at $`10^{-6}`$. All quantities then have comparable magnitude, regardless of the units of the parameters and observables.

**3. Anomalies and covariances.**

```math
\mathbf{A}_\alpha = \mathbf{T}^{-1}\left(\boldsymbol{\alpha} - \bar{\boldsymbol{\alpha}}\mathbf{1}^\top\right),
\qquad
\mathbf{A}_y = \boldsymbol{\Lambda}^{-1}\left(\mathbf{y} - \bar{\mathbf{y}}\mathbf{1}^\top\right),
```

```math
\mathbf{C}_{\alpha y} = \frac{\mathbf{A}_\alpha \mathbf{A}_y^\top}{N-1},
\qquad
\mathbf{C}_{yy} = \frac{\mathbf{A}_y \mathbf{A}_y^\top}{N-1}.
```

**4. Error covariance.** In normalised units, the measurement error variance is 1 and the uncertainty of the literature-consistent values is $`\gamma_i^2`$:

```math
\mathbf{C}_n = \mathrm{diag}\!\left(\mathbf{1}_{n_q},\; \boldsymbol{\gamma}^2\right),
```

which corresponds to $`\mathbf{C}_{dd} = \sigma_d^2\mathbf{I}`$ and $`C_{pp,ii} = (\gamma_i\,\bar{\alpha}_i)^2`$ in physical units.

**5. Innovation covariance.**

```math
\mathbf{S} = \mathbf{C}_{yy} + \mathbf{C}_n + \epsilon\,\mathbf{I},
\qquad
\epsilon = 10^{-5}\,\frac{\left\|\mathbf{C}_{yy} + \mathbf{C}_n\right\|_F}{n_q + n_\alpha}.
```

The small diagonal term $`\epsilon`$ only improves numerical robustness.

**6. Kalman gain.** Computed in normalised units and mapped back to physical units:

```math
\mathbf{K} = \mathbf{T}\,\mathbf{C}_{\alpha y}\,\mathbf{S}^{-1}\,\boldsymbol{\Lambda}^{-1}.
```

**7. Cross-gain zeroing.** The last $`n_\alpha`$ columns of $`\mathbf{K}`$ map the pseudo-observation innovations to parameter updates. Their off-diagonal entries are set to zero, so that each parameter is pulled only towards its own literature-consistent value. Correlations between parameters still act through the measurement columns.

**8. Update.**

```math
\boldsymbol{\alpha}_j \leftarrow \boldsymbol{\alpha}_j + \mathbf{K}\left(\tilde{\mathbf{d}}_j - \mathbf{y}_j\right).
```

**9. Inflation.** If $`\rho > 1`$, the ensemble is inflated around its updated mean:

```math
\boldsymbol{\alpha}_j \leftarrow \bar{\boldsymbol{\alpha}} + \rho\left(\boldsymbol{\alpha}_j - \bar{\boldsymbol{\alpha}}\right).
```

## 5. Remarks

**Inflation and identifiability.** Inflation prevents the ensemble from collapsing in the directions constrained by the measurements. In directions the measurements cannot constrain, the standard EnKF has no information to counteract it, and the spread grows geometrically, as $`\rho^{\,n_{iter}}`$. In the PR-EnKF, the pseudo-observations provide that information. The [tutorial](../tutorials/01_channel_flow.ipynb), Section 5, shows this on a concrete example.

**The numerical jitter.** Since $`\epsilon`$ scales with $`\|\mathbf{S}\|_F`$, a very loose uncertainty ($`\gamma_i \gg 1`$) dominates the norm and makes $`\epsilon`$ significant. In that regime, set `eps_rel=0`.

## 6. Correspondence with the OpenFOAM implementation

The C++ class is `EnKF_multiVariable_multiDomain_clustering`. In the C++ code, the parameter rows of the ensemble matrix are called the α block and the sampled observables the q block.

| Step | Python (`pr_enkf/filter.py`) | C++ |
|---|---|---|
| Initial ensemble | `run()`: `alpha = ...` | `perturbMemberParameters()` (spread `paramPerturbRange`) |
| Perturbed measurements $`\mathbf{d}_j`$, drawn once | `run()`: `d_pert` | `generateAndStorePerturbations()` → `perturbedObsInBIA_` |
| Perturbed pseudo-observations $`\mathbf{p}_j`$, drawn once | `run()`: `p_pert` | `generateAndStorePerturbations()` → `paramPrior` (spread `priorUncertainty`) |
| 1. Augmented vectors | `y`, `d_tilde` | `computeKalmanGain()` step 1 → `globalHx_` |
| 2. Normalisation $`\mathbf{T}`$, $`\boldsymbol{\Lambda}`$ | `T`, `Lam` | `alphaMeanScale`, `obsScale` |
| 3. $`\mathbf{C}_{\alpha y}`$, $`\mathbf{C}_{yy}`$ | `C_alpha_y`, `C_yy` | step 3 → `localPHt_`; step 4 → `HPHt` |
| 4. Error covariance $`\mathbf{C}_n`$ | `C_err` | step 4: `cddUniform`, `C_pp_` |
| 5. Jitter $`\epsilon`$ | `eps_rel * norm(S, "fro") / n` | step 4: Frobenius regularisation |
| 6. Gain $`\mathbf{K}`$ | `np.linalg.solve`, then `T`, `Lam` scaling | step 5 (`LUsolve`), step 6, denormalisation |
| 7. Cross-gain zeroing | `K[:, n_q:] = ...` | loop after denormalisation |
| 8. Update | `alpha + K @ (d_tilde - y)` | `updateEnsemble()` steps 1–3 |
| 9. Inflation | `m + inflation * (alpha_a - m)` | `updateEnsemble()` step 3 (`inflationFactor`) |

The C++ code has two separate entries for the spread of the initial ensemble (`paramPerturbRange`) and of the pseudo-observations (`priorUncertainty`). Both correspond to $`\boldsymbol{\gamma}`$ and are normally set equal.

**Features of the OpenFOAM implementation not included in the Python version:**

* feature-space localisation of the gain;
* parameter bounds with resampling, and non-negativity after inflation;
* safeguards that clip extreme values and replace non-finite ones;
* an observation activity mask;
* multiple simulation domains and observed fields, parameter clustering, and SLURM job management.

## 7. Reproducing the C++ reference step

[`tests/test_cpp_equivalence.py`](../tests/test_cpp_equivalence.py) checks that one Python analysis step reproduces one C++ analysis step to machine precision. The test is skipped until the reference file `tests/data/cpp_reference_step.npz` exists. To generate it:

1. Run one analysis step with the C++ code on a small case (a few parameters, a few observations, about 10 members), with `featureSpaceLocalisation false`, `nClusters 1`, a single domain, and parameter values far from the bounds so that no resampling occurs.
2. In `updateEnsemble()`, write the following to text files: the α block of the ensemble before the update, the q block of `globalHx_`, `perturbedObsInBIA_`, `paramPrior`, and the α block after the update.
3. Convert them to the reference file:

```python
import numpy as np

np.savez("tests/data/cpp_reference_step.npz",
         alpha=np.loadtxt("alpha_before.txt").reshape(n_alpha, n_ens),
         q=np.loadtxt("q.txt").reshape(n_q, n_ens),
         d_pert=np.loadtxt("perturbedObs.txt").reshape(n_q, n_ens),
         p_pert=np.loadtxt("paramPrior.txt").reshape(n_alpha, n_ens),
         alpha_analysis=np.loadtxt("alpha_after.txt").reshape(n_alpha, n_ens),
         sigma_d=obsUncertainty, gamma=np.array(priorUncertainty),
         inflation=inflationFactor)
```

All C++ ensemble arrays are stored row-major as `row * nEnsembles + member`, which matches the `reshape` above.
